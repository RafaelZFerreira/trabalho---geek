🎮 Execução Crachá Geek
📚 Projeto Acadêmico — Programação Orientada a Objetos (POO)
📌 Sobre o Projeto
A Operação Crachá Geek é um projeto acadêmico desenvolvido em Java com o objetivo de aplicar, na prática, os conceitos fundamentais de Programação Orientada a Objetos (POO) .

O projeto simula a organização de participantes de um evento geek, utilizando classes, objetos, atributos e métodos para estruturar as informações.

O cenário utilizado é o evento fictício Tech Geek Experience , organizado pela empresa GeekVerse Eventos .

🎯 Objetivos
Aplicar os fundamentos da Programação Orientada a Objetos.
Desenvolver classes e objetos utilizando Java.
Implementar atributos privados e métodos públicos.
Utilização de getters e setters para manipulação de dados.
Aplicar o conceito de encapsulamento.
Organizar informações dos participantes do evento.
